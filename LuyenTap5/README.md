# Luyện tập 5 - React Native

## Bài tập thực hành

Tạo giao diện React Native đơn giản sử dụng hai thành phần `View` và `Text` để hiển thị nội dung:

```text
Hello React Native
```

## File code

- `App.js`: chứa giao diện chính của bài tập.

## Giải thích

- `View`: dùng làm vùng chứa các thành phần giao diện.
- `Text`: dùng để hiển thị nội dung văn bản.
- `StyleSheet`: dùng để khai báo style cho giao diện.
- `flex: 1`: giúp vùng chứa chiếm toàn bộ màn hình.
- `justifyContent: "center"`: căn giữa theo chiều dọc.
- `alignItems: "center"`: căn giữa theo chiều ngang.
- `fontSize: 24`: đặt kích thước chữ.
- `fontWeight: "bold"`: hiển thị chữ đậm.

React Native sẽ chuyển các thành phần như `View` và `Text` thành các thành phần giao diện native tương ứng trên Android hoặc iOS.
